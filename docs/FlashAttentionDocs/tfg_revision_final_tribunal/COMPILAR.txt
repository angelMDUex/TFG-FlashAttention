TFG FlashAttention - fuentes LaTeX
=================================

Documento principal: principal.tex

Dependencias recomendadas para TinyTeX / TeX Live:

    tlmgr install collection-latexrecommended collection-latexextra collection-pictures collection-langspanish
    fmtutil-user --all

Si se utiliza TeX Live 2025 cuando el repositorio principal ya pertenece a una
release posterior, puede ser necesario seleccionar primero el repositorio
histórico de TeX Live 2025:

    tlmgr option repository https://ftp.math.utah.edu/pub/tex/historic/systems/texlive/2025/tlnet-final

Compilación recomendada:

    latexmk -pdf principal.tex

Para limpiar los ficheros auxiliares:

    latexmk -C

Si el editor LaTeX permite seleccionar un "root document", debe configurarse
principal.tex como documento raíz.
